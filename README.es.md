Realice un gestor de contraseñas en C++, esta enfocado en practicar el manejo de archivos y seguridad.
El proyecto permite guardar y proteger contraseñas utilizando una contraseña maestra, sin guardar texto plano.

Caracteristicas:
  Autenticacion con contraseña maestra.
  Utilizar hashing criptográficp.
  Persistencia en archivos.
  Diseño moular y organizado, con clases.
Seguridad:
  Es mi primer trabajo realizando practicas de seguridad, buscando no almacenar texto plano,
usando libreria sodium, realizando hashes comparando y verificando las claves. 

El proyecto fue desarrollado en entorno Linux, lenguaje C++, STL(string, fsream, vector, etc), compilando con g++.

El obgetivo de este proyecto fue exclusicamente para realizar practicas en seguridad basica,
diseño de software, manejo de archivos y persistencia.
